# ESG Award / ESG Leadership Forum

Демо-версия лендинга с статуэткой **ESG Award 2027** («Барс — хранитель будущего»).

## Локальный запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173`.

## Что внутри

- Hero со статуэткой ESG Award
- Секция премии и программа форума
- Демо-форма регистрации (localStorage)
