# ESG Leadership Forum

Демо-версия лендинга экспертного форума по ESG в Астане.

## Локальный запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173`.

## Что внутри

- Hero с брендом, датой и CTA
- Блоки Environment / Social / Governance
- Программа дня и список спикеров
- Демо-форма регистрации (localStorage)
